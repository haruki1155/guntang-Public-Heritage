# Pangasinan Heritage Digital Showcase

A mobile-first and accessible static tourism showcase highlighting selected destinations in Pangasinan.

## Student

Student Name: GUNTANG, MORRIS JINN R.

## Framework

Vue + Nuxt 3

## Features

- Mobile-first responsive design
- Atomic Design component structure
- Static Site Generation
- Accessible semantic interface
- Lightweight local SVG destination artwork
- GitHub Pages deployment workflow

## Atomic Design Structure

### Atoms

- Button
- Typography
- Color Tokens
- Icon
- Image

### Molecules

- Heritage Card
- Search Form
- Navigation Item

### Organisms

- Heritage Grid
- Header Navigation

## Development

```bash
npm install
npm run dev
```

## Static Generation

```bash
npm run generate
```
